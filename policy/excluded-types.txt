# Exclusion by class, applied to the `type` column of special-accounts.csv.
#
# EMPTY BY DEFAULT. Every line below is commented out, so this file currently
# excludes nothing and the generated balance sheet is unaffected. Uncomment a
# line to remove that whole class from the airdrop.
#
# Matching is on the `type` column, exactly, except that a single trailing `*`
# matches any type with that prefix — which is what makes `Upbit*` cover
# `Upbit #01 (Deposit)` through `Upbit #20 (Staking)`. Matching is
# case-insensitive and ignores surrounding whitespace. A pattern that matches no
# row is an error, so a typo cannot silently exclude nothing.
#
# Addresses are matched on the 20-byte account payload, not the bech32 string,
# so one entry covers the cosmos1… and atone1… encodings of the same key.
#
# WHAT THIS COSTS. Amounts are each class's total in the current sheet, measured
# not estimated. Excluding a class does NOT reduce total supply: the airdrop
# buckets are fixed at 350M (ATOM) and 231M (AtomOne) and are distributed
# proportionally, so every excluded GNOT is redistributed to the remaining
# holders of that bucket. Excluding is a transfer from the named class to
# everyone else, not a burn.
#
#   pattern                    # addrs, GNOT in the current sheet
# ------------------------------------------------------------------

# DokiaCapital*              #  3 addr,  26,628,545.086067 GNOT
