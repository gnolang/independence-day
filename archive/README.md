# archive/ — historical material

Nothing here feeds the pipeline. Everything here is kept because it is **evidence**: it shows how the
numbers were arrived at, cross-checked, or argued about. Deleting any of it would make the airdrop less
auditable, not tidier.

| Item | What it is | Why it is kept |
|---|---|---|
| `prop69-votes/` | An independent extraction of every Cosmos Hub prop-69 vote straight from a gaiad node (`do.sh`, `do2.sh`), plus the results: `votes.csv` (110,937 votes) and `votes-unique.csv` (90,073 unique voters, last vote wins). Its `README.md` is generated by `do2.sh`. | The prop-69 votes the pipeline actually uses arrive pre-merged inside `inputs/cosmoshub-10562840.json.gz`. This directory is the **independent second source** for those votes. If anyone disputes a vote weighting, this is the corroboration. |
| `manfred-recheck/` | @moul's independent re-derivation of the Cosmos Hub snapshot with jq + sqlite + gawk. Ships the `Makefile`, the sqlite build scripts, three summary totals and `shasums.txt`. The 60 GB gaiad export itself is not committed — see the `Makefile`'s `dl-export` target. | A second, independently-tooled derivation of the same source data, with checksums. This is the strongest single piece of evidence that the snapshot is right. |
| `community-review/top-50-review-2022.csv` | A community member's manual review of the 50 largest airdrop recipients (2022), flagging likely airdrop farmers and accounts with no transaction history. | The provenance of several `policy/special-accounts.csv` entries, and the original argument for having an exclusion list at all. |
| `airdrop-sim-v3.py` | A third-party pandas/openpyxl simulation of the distribution. | **Superseded and non-authoritative.** It hard-codes local Windows paths and uses a *different* weight table (0.7 / 1.1 / 1.3 / 0 multipliers) from the one that shipped. Kept so the discrepancy stays visible rather than being lost — do not use it to check your balance. |
| `gnotest-2022/` | 666 KB of signed genesis transactions from the 2022 `gnotest` chain (`/vm.m_call` into `gno.land/r/users`). | Predates the airdrop work entirely and is unrelated to it. Kept because this may be the only surviving copy; if the same file exists in `gnolang/gno`, this copy can go. |

## Provenance

Everything here was moved with `git mv`, so `git log --follow <path>` still reaches the original history
under the old path.
